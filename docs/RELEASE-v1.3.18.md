# 蓝斗篷启动 v1.3.18 公开预览版

包含 v1.3.12 至 v1.3.18 的累计修改，沿用 WPF、原 JSON 数据格式和原有启动、分组、网站及图标管理功能。不加入 Dock、桌面状态组件或自动置顶建议。

## 界面与工作空间

- 移除高亮色设置，旧高亮色偏好不再影响界面，选中和开关改用中性色。
- 顶部只保留搜索与新增图标；通过搜索图标或 Ctrl + K 展开输入框，框内不再显示提示及快捷键文字。
- 分组文件夹缩小约 20%，仅显示名称并自动换行。名称位于图形缩放层之外，改善中文清晰度。
- 置顶仅在工作空间显示，图标横向自动换行，支持拖动排序动画。独立 `PinnedSortOrder` 不改变分类和分类内排序，并支持备份导入、合并及旧分组恢复路径。
- 左侧精简；分类管理、主题统一放入设置，新建分类位于“设置 → 管理分组”。收藏和最近使用等底层数据保留。
- 移除应用悬停三个点按钮，保留右键菜单；移除右上角三个窗口按钮，通过 Esc、点击外部收起或托盘退出。
- 使用 Windows UI 字体和中文回退，启用 ClearType、Display 文本格式、固定字形提示、布局取整和像素对齐。

## 所有应用与搜索

- 管理分组新增“显示所有应用入口”；关闭后安全返回工作空间或其他可见分类。
- 新增“所有应用中显示隐藏分组的应用”；开启后，所有应用包含隐藏的自定义分类、系统附带应用及配套工具，侧栏和工作空间仍遵循隐藏设置。
- 所有应用按普通分类顺序展示，置顶状态不再影响其排序及拖动分区。
- 搜索始终覆盖全局，包含应用、网站、收藏文件夹、标签、隐藏分类和虚拟文件夹成员，不受上述显示开关影响；清空恢复原视图。

## 系统适配与数据整理

- 开始按钮优先使用 UI Automation 的实际区域，后台约每半秒重新识别，适应居中任务栏；居中时在相应屏幕底部居中展开。
- 主窗口不显示任务栏图标，保留托盘入口。新增隐藏/恢复所有桌面图标设置，不删除文件，保存偏好并在启动时应用。
- 自动扫描识别同一程序重复入口，包括 WPS、豆包、夸克、Bandizip 的来源参数和数字版本目录。整理时保留分类、图标、置顶、收藏和标签，原条目存入 `DuplicateEntries`。
- 手工入口、浏览器不同配置、文档参数、WPS 不同组件及专业软件不同安装版本不强制合并。
- 首次升级移除“社交、创作、娱乐、效率”四个旧默认分类，将其中入口与虚拟文件夹移到未分组应用，并清理对应旧归类规则。迁移只执行一次，之后可以自行创建同名分类。
- 系统附带应用和配套工具的显示统一在管理分组控制，沿用旧显示状态。
- 最小化系统命令改为收起，并处理其他最小化路径；收起时关闭菜单并禁用提示，重新打开时恢复。
- 公开版同步补齐重复项恢复记录及其图标的备份、合并、重复导入，以及旧分组恢复路径中的置顶顺序。

## 保留数据的更新步骤

1. 在旧版设置中导出一份 `.lumabackup`，并备份整个旧程序文件夹。
2. **右键托盘中的蓝斗篷启动图标 → 退出蓝斗篷启动。** 只按 Esc 或点击外部是收起，旧进程仍会运行；此时打开新程序可能只唤醒旧版。
3. 将本次运行包解压到临时目录，把 `BlueCloakLauncher.exe`、同名 `.exe.config`、`assets` 和说明文档复制到原程序目录。
4. 保留原 `data`、`personal-data`、`personal-seed.json`、`group-template.json`、自定义图标、网站资源及备份目录，不以默认文件覆盖它们。原可执行文件名如有不同，同时调整对应 `.exe.config` 文件名。
5. 启动新版本，在设置核对版本、分组、网站及置顶顺序。更换程序路径或文件名后，在设置中重新应用登录启动偏好。

公开运行包只包含通用空分组，不含发布者的个人数据；第一次运行在本机发现应用。旧配置新增字段使用兼容默认值，首次保存前保留原配置快照。
