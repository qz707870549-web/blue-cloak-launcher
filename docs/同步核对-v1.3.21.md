## 数据保护

安装器只写入发行文件；卸载按文件清单删除，禁止递归删除选定安装目录。分组、图标和配置保留在原数据目录。便携版与不同安装目录之间需通过 `.lumabackup` 迁移，不自动导入其他位置的数据。

保留前次公开版同步中的 `PinnedSortOrder` 恢复、`DuplicateEntries` 图标资源备份和合并保护。原有收藏、网站、隐藏分类及手动排除记录继续沿用。

## 发行与验证

`build-installer.ps1` 补充 `CompilerPath` 参数，和已有 `verify.ps1`、`build.ps1` 一致，方便使用固定工具缓存进行隔离构建。安装工具仍固定版本并保留许可。

源码包已超过 GitHub 网页单次 100 个文件上限，更新说明改为两批上传：先上传 `src` 文件夹，再上传其余根文件及 `tests`、`docs`、`installer`。两批提交后才创建版本标签。

398 项离线检查及离屏图片不代表真实安装、升级、卸载、登录启动、任务栏、游戏或白框问题已经完成验证。本次不操作现用程序、桌面和系统设置；真实安装仍未测试，安装文件未签名。
