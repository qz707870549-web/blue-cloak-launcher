# 隐私与数据

公开版内嵌的 `src/default-groups.json` 只有通用分组名称，没有应用、网站、路径、图标缓存或个人匹配规则。

软件运行后会在本机保存：应用快捷入口、分类和排序、网站与文件夹收藏、自定义图标、启动历史、主题与窗口设置，以及诊断日志。

这些内容位于程序数据目录。备份文件可能包含完整网址、本机安装路径与嵌入图标，**不要把个人备份上传到公开仓库**。

网站图标与标题获取会访问所添加的网址，站点可能根据普通网络请求记录 IP 等访问信息。编译脚本会访问 NuGet 下载固定版本编译器。未加入遥测服务或向维护者上传应用列表的功能。

开始按钮和 Win 键功能在程序运行期间使用 Windows 输入钩子；键盘钩子用于判断 Win 单键与组合键，不将普通输入保存为日志。自启动在启用后注册当前用户登录任务与备用启动项，不申请管理员权限。

发布程序使用白名单打包，不复制运行数据。`.gitignore` 只是防误提交辅助措施，网页上传前仍应检查文件清单。
