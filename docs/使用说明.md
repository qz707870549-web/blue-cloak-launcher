# 使用说明

1. 解压公开运行包到可写的固定文件夹，双击 `BlueCloakLauncher.exe`。首次运行会扫描本机应用。
2. 左侧选择分类；工作空间显示分类文件夹，点击进入。单击应用打开已有窗口或启动应用。
3. 应用右键可以调整分类、置顶、收藏或更换图标。删除入口不会卸载程序或删除实际文件。
4. 通过添加菜单加入应用、网站、文件夹。网站图标获取需要访问该网站。
5. 设置中可开关工作空间，调整主题、开始按钮和 Win 键入口；附带应用和配套工具的显示统一在“管理分组”控制。
6. 主窗口显示时保持置顶；点击外部或按 Esc 收起，后台继续运行。托盘菜单可退出。
7. 设置 → 数据与支持 → 登录 Windows 后启动，可启用登录任务与备用启动项。出现降级提示时查看 `data/startup.log`。
8. 设置 → 应用库中可导入和导出单文件分组备份。公开包没有你的个人分组，可自行导入自己的 `.lumabackup`。

更新前通过托盘菜单退出旧版，把新程序、`BlueCloakLauncher.exe.config` 和 `assets` 复制到原目录；保留 `data`、`personal-data`、个人种子和图标目录。不要同时运行多个版本。

源码编译输出 `LumaDock.exe`，公开发行包名为 `BlueCloakLauncher.exe`。可执行文件重命名时，应将对应 `.exe.config` 一起改为相同前缀。

关闭登录自启动后再删除或移动不再使用的程序。只退出程序会停止入口接管，但不会替你关闭已启用的自启动。

更新至 v1.3.8 后，电脑分类包含此电脑、回收站、控制面板；常用系统应用默认显示在工具或原有自定义分类。首次升级会在后台补查，稍候即可。未安装的系统应用不会自动安装。

更新至 v1.3.11：搜索框支持输入、主题颜色和 Ctrl + K；当时支持跨可见分类搜索；v1.3.18 已改为包含隐藏分组的全局搜索，清空返回原视图。新增未分组应用入口，内部继续使用未分类标识，首次升级会显示。程序运行时会监听常用安装入口和配置目录，约两秒稳定后自动补查，另有安装延迟补查、五分钟定期补查和打开窗口时的补查；F5 可主动刷新。扫描只增量补充，不删除旧数据。

Win 键和系统菜单补救并未进行真实游戏验证，权限隔离、反作弊或安全桌面可能限制效果，不能保证原生菜单零闪现。

更新至 v1.3.13：开始按钮优先使用 UI Automation 的按钮区域，不再用 XAML 任务栏宿主 HWND 覆盖坐标；按钮区域后台每半秒重新识别，适应任务栏位置变化。任务栏居中时启动器在所在屏幕底部居中。主窗口不再显示任务栏应用按钮，仍可通过开始按钮、Win 键和托盘打开。设置 → 窗口与交互 → 隐藏所有桌面图标，可隐藏/恢复应用、文件夹和系统图标；不会删除文件，失败时提示并保留原配置。隐藏偏好保存在配置中，程序启动时重新应用。
本次验证使用隔离配置和无窗口测试，没有改变本机桌面图标或任务栏对齐，没有进行真实 Explorer 点击验证。

更新至 v1.3.14：顶部只显示搜索和新增两个图标，与窗口控制按钮同排；搜索图标或 Ctrl + K 展开输入框，原多行工具栏移除，内容区上移。右键菜单和原有快捷键保留。
扫描现在会统一同一可执行程序的重复入口，并识别 WPS、豆包、夸克、Bandizip 的来源参数和数字版本目录。启动时会整理已有的自动扫描重复项，保留分类、自定义图标、置顶、收藏、标签等信息。合并掉的原条目保存在配置的 DuplicateEntries 中，可用于恢复。手工添加的入口、明确不同的分类、浏览器配置、文档启动参数、WPS 不同组件及专业软件不同安装版本不强制合并。

更新至 v1.3.15：工作空间分组文件夹只显示分组名称，隐藏数量及说明。顶部置顶区移除标题和折叠按钮，只保留图标（悬停显示名称），支持带过渡动画的拖动排序和自动换行。置顶顺序独立保存，不改变应用所属分类或分类内的排列，并随分组备份导入导出。
左侧移除收藏、最近使用、下载、新建分类及分类管理、主题快捷入口；通过设置调整主题，通过 设置 → 管理分组 → 新建分类 创建分类。原分组、应用及收藏等数据仍然保留。

更新至 v1.3.16：默认分组移除社交、创作、娱乐、效率。首次升级时，这四组内的应用及文件夹移至未分组应用，保留入口、图标、置顶等数据；同时清理旧分组的自动归类规则，避免再次自动生成。此清理只执行一次，之后可以自行新建同名分组。
设置页面删除显示系统附带应用和显示软件配套工具两个重复开关；在 设置 → 管理分组 中统一控制，并同步旧设置中的显示状态。选中与开关效果统一为中性色，旧紫色偏好不再应用；应用卡片取消强调色选中边框。

更新至 v1.3.17：删除应用卡片悬停时的三个点按钮，全部操作仍可通过右键菜单完成。工作空间分组文件夹卡片由 228 高调整为 182.4，宽度按 250 的原基准调整为 200，间距同步缩小，并采用自动换行布局。右上角最小化、最大化/还原、收起三个按钮不再显示；仍可按 Esc、点击外部或通过托盘收起与退出。
白色小矩形排查：只读检查时本进程所有窗口均为隐藏状态，未能现场确认截图白框归属。修复无边框且隐藏任务栏图标时仍允许系统最小化的代码风险：在原生系统命令进入最小化前拦截并改为收起；对其他途径触发的最小化补充隐藏处理。窗口隐藏时关闭菜单、禁用悬停提示，重新打开后恢复，避免独立弹层残留。以上均通过无窗口测试验证，未操作桌面复现。
更新前请先通过托盘退出旧版，再将程序、配置和 assets 覆盖到原目录，保留 data、personal-data 和个人图标等数据。旧进程仍运行时，新版本会通知旧进程打开，可能看不到此次修改。

更新至 v1.3.18：设置 → 管理分组 新增显示所有应用入口、所有应用中显示隐藏分组的应用两个开关。隐藏所有应用入口后，当前页面安全返回工作空间或其他可见分类。开启包含隐藏分组后，所有应用也会包含被隐藏的自定义分类、系统附带应用和配套工具；工作空间和侧栏仍遵循分类隐藏设置。
置顶图标条只在工作空间显示；所有应用按普通分组与排序展示，拖动时不再因置顶状态分隔。搜索框移除提示文字及快捷键文字，搜索始终覆盖全部现有应用，包括隐藏分组及文件夹成员，不受所有应用隐藏开关影响。
字体使用 Windows 系统 UI 字体及中文回退，启用 ClearType、Display 文本格式、固定字形提示和像素对齐。分组标题移出文件夹缩放图层，避免文字随图形缩放变糊或产生不规则边缘。实际显示效果仍与显示器 DPI 和系统字体渲染环境有关；本次检查使用离屏渲染，没有操作桌面。


更新至 v1.3.19：新增标准 Windows 安装版，简体中文向导、默认桌面快捷方式、开始菜单入口，以及 Windows 已安装应用中的卸载入口。支持当前用户安装与覆盖升级，保留分组和图标数据。原便携版可导出 .lumabackup，再导入安装版。卸载时仅清理属于当前安装路径的启动注册。详见 docs/安装与发行.md。安装包尚未进行真实机器安装测试，也尚未数字签名。

更新至 v1.3.20：新增工作空间简约卡片样式。设置 → 外观 → 工作空间分组样式，可在层叠文件夹与简约卡片之间切换，即时生效并保存偏好。原有用户默认保留层叠文件夹。简约卡片使用分组图标和名称，底部预览最多四个真实、可见的分组应用图标；不显示数量或说明，支持深浅色和自动换行。两种样式共用原有分组打开及选择逻辑，不更改分组内容、应用顺序或置顶数据。分组名称使用原生字体绘制，不进行图形缩放。

更新至 v1.3.21：工作空间置顶应用上方新增 24 个逻辑像素留白，保留原有下方间距和两种文件夹样式。顶部新增（加号）菜单补充“从文件夹导入”：选择免安装程序解压后的目录，向下扫描四层，并将目录加入后续自动补查范围。
新安装的程序可通过桌面、开始菜单、Windows 应用列表和注册的 App Paths 自动补查；常用入口变化稳定约两秒后扫描，并有五分钟定期补查。未生成快捷方式、未注册且位于未添加目录的便携程序，需要手动导入。ZIP 压缩包本身不会自动解压或作为应用启动；请先解压，再导入软件目录。扫描只增量补充，保留原有分组、网站和置顶信息。
