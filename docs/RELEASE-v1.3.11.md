# 蓝斗篷启动 v1.3.11 公开预览版

## 搜索输入和结果

- 修复紧凑搜索框沿用通用 TextBox 样式后文字显示视口高度为零的问题。
- 使用保留 PART_ContentHost 的专用单行模板，取消上下内边距和通用最小高度限制。
- 输入文字和光标随主题切换，放大镜区域可点击聚焦，保留 Ctrl + K。
- 跨可见分类搜索应用、收藏文件夹、网站和标签，清空后恢复原视图。

## 新应用自动发现

- 监听桌面、公共桌面、开始菜单、公共开始菜单及配置的扫描目录。
- 文件变化稳定约 2 秒后后台扫描，并在约 15 秒后安排一次安装过程补查。
- 每 5 分钟定期补查；重新打开窗口时，距上次自动扫描超过 1 分钟则安排补查；F5 可刷新。
- 增量补充入口，不用不完整扫描结果替换已有应用列表。
- 保留已有分类、收藏、手动置顶、自定义图标和排除记录，新增目录的监听可以动态更新。
- 新增“未分组应用”入口，内部继续保存“未分类”标识；首次升级显示该分类，已有匹配规则继续生效。

## Win 键与原生开始菜单交接

- 桌面、窗口和游戏使用同一套 Win 单键接管逻辑，组合键按顺序转发。
- 只跳过启动器自身带专用标记的重放，处理其他来源的转发事件。
- 定期恢复监听，清理遗漏释放造成的残留状态；退出时释放监听。
- 结合 IAppVisibility、前台通知和低频复核补救原生菜单漏出，成功后确保启动器显示，重复通知不再次关闭启动器。
- 关闭请求只投递给核验了进程、系统路径和必要窗口类的菜单宿主或任务栏，不向全局输入流注入 Esc。
- 每轮最多尝试两次收起，3 秒超时；同一次未结束的菜单显示不会被定期复核反复重启补救。

## 数据与升级

先退出旧版，把新程序、对应 exe.config 和 assets 覆盖到原程序目录。

**保留 data、personal-data、personal-seed.json、图标目录和现有备份；不要删除原数据目录或拿通用示例配置覆盖它。** 升级前可在设置中导出分组备份。

公开包仅带通用默认分类，不含个人应用、网站、路径或分组备份。首次升级显示“未分组应用”是本次迁移行为，其他自定义分类和隐藏设置保留。
