# 安装版与便携版

朋友首次使用时，发送 `蓝斗篷启动-v版本号-Windows-x64-安装程序.exe` 即可，不必让对方处理 ZIP 内的文件。

安装向导为简体中文，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\BlueCloakLauncher`，无需管理员权限。桌面快捷方式默认勾选，可自行取消；开始菜单入口和 Windows 已安装应用中的卸载入口会一起建立。安装完毕可选择立即启动。

支持 64 位 Windows 10/11，需要 .NET Framework 4.8 或更新兼容版本。向导会检查运行条件，缺少框架时显示官方安装地址，不会静默安装系统组件。

## 保留数据

安装包只包含程序、资源和许可证，不包含维护者的私人分组、网站及备份。重复安装到原安装目录不会覆盖已有的 `data`、`personal-data`、个人种子及图标。升级前应从系统托盘退出旧版，安装器检测到现有实例会提示退出。

从其他文件夹的便携版迁移：先在旧版导出 `.lumabackup`，退出旧版，安装新版本后导入备份。安装器不会搜索并复制电脑上的私人文件。

卸载可通过 Windows“已安装的应用”或开始菜单入口进行。卸载只删除安装清单中的程序文件和快捷方式，保留分组与图标数据；只清理指向当前安装路径的开机启动项，不移除其他便携副本的启动注册。

## 构建

在 PowerShell 中执行 `./build-installer.ps1`，会先运行完整离线测试，再生成 `release` 下的安装程序和 SHA-256 校验文件。已经完成验证时可加 `-SkipVerify`。工具包保存在项目 `artifacts/tools`，不需要运行 NSIS 自身的安装程序。未来版本号从 `src/VersionInfo.cs` 自动读取。

已有编译工具缓存时，可传入 `-CompilerPath` 指向 Roslyn `csc.exe`、`-NsisPath` 指向 NSIS `makensis.exe`。这两个参数只选择构建工具，不改变安装行为；编译安装程序不会运行生成的安装文件。

安装清单在 `installer/launcher.nsi`。增加发行资源时，要同步维护安装和卸载的文件白名单，不能递归删除用户选择的安装目录。

当前安装包没有代码签名证书，Windows 可能显示未知发布者或信誉提示。正式公开发行时可使用维护者自己的代码签名证书签名，不要把证书私钥放入源码。

开发验证只执行编译、配置测试和文件检查，没有在当前电脑安装、创建桌面快捷方式、注册启动项或卸载应用。实际安装/升级/卸载流程仍需在测试机器上验证。
