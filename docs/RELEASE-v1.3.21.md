# 蓝斗篷启动 v1.3.21 公开预览版

今日更新（2026-10-21），包含 v1.3.19 至 v1.3.21 的累计修改，保留原有公开版功能和用户数据，不加入 Dock。

## Windows 安装程序

- 新增简体中文安装向导，默认创建桌面快捷方式和开始菜单入口，支持覆盖升级及 Windows 标准卸载。
- 默认安装到当前用户的 `%LOCALAPPDATA%\Programs\BlueCloakLauncher`，无需管理员权限。
- 安装和卸载使用发行文件白名单，保留用户分组、网站、配置及图标数据。检测到程序仍在运行时会提示先退出。
- 便携版可通过 `.lumabackup` 备份迁移到安装版。安装器不会自动查找或搬移其他目录中的个人数据。

## 工作空间与导入

- “设置 → 外观 → 工作空间分组样式”新增“简约卡片”，同时保留“层叠文件夹”。
- 简约卡片显示分类图标、分组名称及最多四个真实、可见的应用图标，支持深浅色和自动换行。
- 切换样式不改变分组内容、应用顺序或独立置顶顺序，原用户默认保留层叠文件夹。
- 工作空间置顶应用上方增加 24 个逻辑像素留白。
- 顶部“＋”新增“从文件夹导入”，可扫描已解压的软件目录及向下四层。选定目录会加入后续自动补查范围。
- ZIP 压缩包须先解压，不会自动解压或直接运行。未生成快捷方式、未注册且位于未添加目录的便携程序，需手动导入。

新安装程序自动发现是已有功能，本次补充文件夹导入入口并明确识别范围；扫描只增量补充，保留已有分组、网站、图标和置顶数据。

## 下载与更新

- 安装版：`蓝斗篷启动-v1.3.21-Windows-x64-安装程序.exe`。
- 便携版：`BlueCloakLauncher-v1.3.21-public-Windows-x64.zip`，解压后运行 `BlueCloakLauncher.exe`。
- 各运行文件附带 `.sha256` 校验文件。GitHub 自动生成的 Source code 是源码，不能直接运行。

升级前先在旧版导出 `.lumabackup`，并通过托盘菜单退出旧进程。安装版升级到原安装目录；便携版覆盖程序、同名 `.exe.config` 和资源文件，保留 `data`、`personal-data`、个人种子、网站资源、自定义图标及备份。便携版迁移到新的安装目录后，在设置中导入之前的备份。
