# 蓝斗篷启动 v1.3.8 公开预览版

## 搜索修复

- 修复在当前分类内输入其他分类应用名称后不显示结果的问题。
- 搜索覆盖所有可见分类中的应用、网站、收藏文件夹及自定义标签。
- 在收藏、最近使用和虚拟应用文件夹中搜索也能找到其他分类的入口。
- 清空搜索后回到原分类或原应用文件夹；隐藏项目仍保持隐藏。
- 修正搜索结果数量和位置提示。

## 系统图标与应用识别

- 新增“此电脑、回收站、控制面板”快捷入口，并从 Windows Shell 获取真实图标。
- 改善打包应用的高分辨率图标识别与提取。
- 改善计算器、记事本、截图工具、画图、设置等常用系统应用的识别和显示。
- 对同一系统应用的经典入口和打包入口去重，保留已有分类及手动置顶设置。
- 升级时可在后台补充识别；用户主动移除的入口不会因别名重新出现。

## 下载与更新

下载附件 `BlueCloakLauncher-v1.3.8-public-Windows-x64.zip`，解压后运行 `BlueCloakLauncher.exe`。

更新前退出旧版，把新程序、配置文件和 assets 复制到原目录，保留 data、personal-data 和图标目录。建议先导出分组备份。

公开包不包含私人分组、网站、个人路径或备份。个人版 ZIP 不用于公开发布。

Windows 10/11 x64，需 .NET Framework 4.8。验证采用隔离测试和本机 Shell 图标只读提取，没有运行应用主入口、安装全局钩子或修改系统启动项；真实开机和多设备交互仍需验证。
