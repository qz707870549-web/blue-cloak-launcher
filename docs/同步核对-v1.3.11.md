# v1.3.11 同步核对

## 同步范围

核对并保留本地 v1.3.11 已实现的搜索专用模板、自动增量发现及统一 Win 输入状态处理。公开版仍沿用 C# / WPF / .NET Framework 4.8 和原 JSON 配置格式。

本次进一步补齐：

1. 将原生菜单关闭从全局 Esc 输入改为绑定已核验 Shell HWND 的定向消息。即使前台切换到游戏或编辑器，消息目标也不会跟随改变；识别失败时不发送。
2. 原生菜单交接增加可见性边沿记录。超时或用户主动收起后，同一次菜单显示不会因重复通知重新启动补救；菜单隐藏再显示后才重新允许一轮补救。
3. 扫描目录变动后同步增删 FileSystemWatcher，避免新增自定义目录必须重启才开始监听。
4. 加入对应回归检查，以及光标颜色、单行模板内边距和高度限制检查。

## 已验证

- `SearchTests`：跨分类、网站、文件夹、标签搜索，清空恢复原视图；浅色、深色及 800/1000/1440 宽度下直接检查 PART_ContentHost 的文字视口；文字与光标主题颜色。
- `DiscoveryRefreshTests`：增量追加、空扫描不删旧入口、用户元数据和排除记录保留、规则归组、未分组分类迁移；隔离目录真实文件事件及监听路径增删。
- `FullscreenWinKeyTests`、`NativeStartHandoffTests`：Win 单键、组合键重放、转发事件、自有标记过滤、残留状态恢复；重复通知、有限重试、超时、用户取消；定向消息和可信系统宿主判定。
- 原数据、图标、窗口尺寸、工作空间等既有离线检查继续通过。

完整套件共 283 项通过。用户配置兼容验证使用副本，未将测试结果写入正在使用的数据目录。
