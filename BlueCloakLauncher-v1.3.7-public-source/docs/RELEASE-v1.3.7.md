# 蓝斗篷启动 v1.3.7 · 首个公开版

- 整理可编译源码、离线验证与公开包脚本。
- 默认分组改为通用空分类，首次扫描本机应用。
- 不包含私人应用清单、网站、收藏文件夹路径、个人备份或缓存图标。
- 保留分组管理、工作空间开关、手动置顶多行、网站、文件夹收藏和备份导入导出。
- 保留开始按钮与 Win 单键入口、主窗口置顶、Esc / 点击外部收起。
- 登录启动可选，包含延迟启动、失败重试与备用启动项。
- 移除 Dock、桌面状态组件及自动置顶建议。

环境：Windows 10/11 x64、.NET Framework 4.8。

请下载 `BlueCloakLauncher-v1.3.7-public-Windows-x64.zip`，解压后运行 `BlueCloakLauncher.exe`。Source code 压缩包需自行编译。

已执行隔离的离线验证；真实开机登录、系统入口接管和窗口层级尚未在多台设备上验证。首次公开发布建议先标记为预发布，收集反馈后再发布稳定版。
